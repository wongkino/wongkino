## 關於

公開出來的東西，多半是自己真的在用的：密碼庫異地備份、媒體庫帳號助手、下載器介面，還有語音相關的機器人。

喜歡把重複的步驟收成一個小工具，然後讓它安靜地跑在自己的機器上。
