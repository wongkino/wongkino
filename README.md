## 關於

公開出來的東西，多半是自己真的在用的：把公網位址寫進 Cloudflare、密碼庫異地備份、香港天文台天氣板，還有語音與下載相關的小工具。

喜歡把重複的步驟收成一個小工具，然後讓它安靜地跑在自己的機器上。
